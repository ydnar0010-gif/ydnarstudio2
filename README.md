# Ydnar Studio

Professional portfolio for Ydnar Camporedondo. Production domain: https://ydnarstudio.space/

## Preview

Open `index.html` or serve this directory with a static HTTP server. No dependencies, environment variables, or build step are required.

## Vercel

Use the existing `ydnarstudio` project. Framework: Other. Root: repository root. Output: `.`. The configuration is supplied in `vercel.json`. Connect `ydnar0010-gif/ydnarstudio2` and use `main` as the production branch.

## Features

Responsive dark-and-gold design, geometric YS logo, mobile navigation, accessible project dialogs, live Balanse cashflow calendar and Tinda inventory showcases with actual dashboard snapshots, a workflow concept demo, project inquiry composer, portrait, and resume.

Concept demos use fictional data and do not create real bookings or connect to a CRM. Project inquiries open the visitor’s email app; visitors review and send their own messages. The website does not store personal details.
